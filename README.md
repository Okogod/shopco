# ShopCo

> A modern, responsive e-commerce frontend web application built for browsing products, filtering categories, and seamless page navigation.

## ✨ Features

- **Product Exploration:** Browse an extensive list of products categorized systematically.
- **Dynamic Product Views:** Deep-dive into individual product pages with rich descriptions and pricing.
- **Responsive Layout:** Optimized UI design tailored for desktop, tablet, and mobile screens.

## 🛠️ Tech Stack & Prerequisites

Before setting up, ensure you have the following installed:

- **Runtime Environment:** Node.js v20.x or higher
- **Core Technologies:** React 18+, TypeScript
- **Routing:** React Router Dom v6

## 📦 Installation

Get a local development instance running by executing these steps in your terminal:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/okogod/shopco.git
   cd shopco
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

## 🚀 Usage

To start the application locally in development mode with hot-reloading:

```bash
npm run dev
```

Once started, open your browser and navigate to the local URL provided in your terminal (typically `http://localhost:5173`).
